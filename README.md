# COSD-Card-
所有人开局需要在［公示角色］库内选择一名角色，之后在游戏结束前不可再选择角色，所有人开局获得［开局牌］中的所有牌，每回合在［抽牌卡池］中随机抽取一张牌

需要留出预设的卡牌类型库就可以了，方便为每种卡牌和桌面上传贴图。

除此之外，卡牌一共分为7种，已预设六个小卡牌类型库，其中分为:
［数值］［基础］［条件基础］［公示角色］［放置角色］［事件］［转化］［环境］。
除此以外，还要建立［开局牌］和［抽牌卡池］两个大牌库。
并且［数值］，［条件基础］和［公示角色］不在［抽牌卡池］中

管理员控制所有玩家场景，及选择出牌（单机程序，并非联机游戏）
最大人数为8，因此至少有8个独立的可自由切换的选牌场景页面
 程序中玩家一共有两个数值条，命名为“A值”和“B值”即可，游戏中的卡牌会影响自己或其他玩家的数值效果，也就是说此程序需要支持在每个玩家场景中通过打出卡牌来自由影响别的玩家的数值

显示总数据和计算结果的场景页面便于管理员操作
